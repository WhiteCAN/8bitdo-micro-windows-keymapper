# 프로토콜 메모

이 문서는 MicroKey Studio를 위해 정리한 공개 가능한 프로토콜 관찰 내용만 담습니다.

## 관찰된 BLE UUID

- Service UUID: `0000FF10-0000-1000-8000-00805F9B34FB`
- Write/notify characteristic UUID: `0000FF13-0000-1000-8000-00805F9B34FB`

## 관찰된 앱 흐름

1. 공식 앱이 BLE 앱 모드의 Micro를 검색합니다.
2. BLE 세션에 연결합니다.
3. Micro 서비스와 characteristic을 찾습니다.
4. 알림을 구독합니다.
5. report-enable 및 configuration 패킷을 전송합니다.
6. 저장 또는 commit 패킷을 전송합니다.

## 메모

- 전체 설정은 오프셋 `0x00`, `0x2D`, `0x5A`, `0x87`의 45바이트 페이지 네 개로 읽습니다.
- 공식 모바일 앱에서 `Disable Sleep`을 OFF → ON → OFF로 저장한 세 캡처를 비교했습니다.
- OFF 반복 캡처 두 개의 180바이트 설정은 완전히 같았습니다.
- ON과 OFF의 유일한 설정 차이는 전체 오프셋 `0x03`이며 ON=`0x01`, OFF=`0x00`입니다.
- 오프셋 `0x03`이 확인된 `0x00/0x01`이 아니면 해당 값은 해석하거나 정규화하지 않고 원본 그대로 보존합니다.
- 응답 페이지 CRC는 값에 따라 바뀌며, 쓰기 패킷은 변경된 45바이트 페이지의 CRC16을 다시 계산합니다.
- 저장은 현재 전체 설정을 다시 읽은 뒤 확인된 필드만 변경하고, 쓰기 후 새 전체 설정을 다시 읽어 요청 값과 비교합니다.
