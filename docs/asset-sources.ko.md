# Asset 출처

이 프로젝트는 외부 시각 자료의 출처를 이 문서에 기록합니다. 배포 사용자와 기여자가 이미지 출처를 확인할 수 있게 하기 위함입니다.

## 8BitDo Micro 제품 이미지

- 파일: `src/MicroKeyStudio.App/Assets/Images/8bitdo-micro-blue.png`
- 파일: `src/MicroKeyStudio.App/Assets/Images/8bitdo-micro-blue-front.png`
- 출처: `https://www.8bitdo.com/images/2023/micro/micro-blue.png`
- 페이지: `https://www.8bitdo.com/micro/`
- 용도: 매핑 화면 안의 지원 기기 식별용 제품 이미지. `front` 파일은 버튼 위치를 읽기 쉽게 만들기 위해 같은 공식 원본 이미지에서 정면부만 crop한 파일입니다.

8BitDo, 8BitDo Micro 및 관련 제품 이미지는 각 권리자에게 있습니다. 이 비공식 프로젝트는 지원 기기를 식별하기 위한 목적으로만 제품 이미지를 사용합니다.
