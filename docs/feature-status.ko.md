# 기능 상태

최종 갱신: 2026-08-19 (`0.1.0-preview.31`)

## 2026-10-05 UI 개선 (미배포)

- 사이드바에 세로 스크롤을 추가하고 하단 안내와 작업 버튼을 다른 행에 배치했습니다.
- 매핑 도식을 창 크기에 맞춰 함께 축소하며, 키 선택 영역은 스크롤할 수 있습니다.
- `적용`을 `PC 프로필에 적용`으로 변경했습니다. 편집 중에는 기기 작업 버튼을 숨기고 기기 저장 명령도 차단합니다. 적용하거나 취소한 뒤 매핑 화면에서 기기에 저장합니다.
- 기기 연결 상태와 저장할 수 없는 이유를 화면에 표시합니다.
- 선택한 매핑과 연결선만 강조하고, 슬롯 번호는 매핑 버튼의 툴팁으로 이동했습니다.
- 프로필·언어·자유 입력·키 캡처·매핑 버튼의 접근성 이름을 보완했습니다.

검증: 전체 자동 테스트 184개 통과. 로컬 앱에서 한글 개요·편집 화면, 사이드바 안전 안내 접근, 접근성 트리를 확인했습니다. 기기 쓰기·복원과 디스플레이 배율별 검증은 이번 UI 작업에서 수행하지 않았습니다.

## 공개 버전 기능

| 기능 | 상태 | 설명 |
| --- | --- | --- |
| 기기 찾기 및 매핑 읽기 | 동작 | 검색된 Micro에 자동 연결하고 현재 기기 매핑을 읽습니다. |
| 키 매핑 편집 | 동작 | 키 선택, 실제 키보드 입력, 자유 입력 동시 키를 지원합니다. |
| 물리 버튼 연결 표시 | 동작 | 이미지 위 연결선과 버튼 중심 종점으로 16개 매핑 행의 위치를 표시합니다. |
| 기기에 저장 | 동작 및 실기기 확인 | 저장 직전 백업을 만들고 쓰기 후 전체 설정을 다시 읽어 검증합니다. |
| 불러온 값으로 되돌리기 | 동작 | 화면과 선택한 PC 로컬 프로필을 마지막 기기 읽기 값으로 되돌립니다. 기기에는 쓰지 않습니다. |
| 최근 백업 복원 | 조건부 동작 | 기기 연결과 유효한 백업이 필요합니다. 자동화 검증은 완료됐고 실기기 최종 복원 확인은 남아 있습니다. |
| 프로필 추가, 이름변경, 삭제 | PC 로컬 전용 | 프로그램의 로컬 프로필 파일만 변경합니다. 기기 프로필 목록은 변경하지 않습니다. |
| 기기 프로필 이름과 목록 | 미구현 | 현재 프로토콜에서 프로필 메타데이터를 확인하지 못했습니다. |
| 슬립 비활성화 | 구현, PC 저장 실기기 확인 대기 | 공식 앱 반복 캡처로 오프셋 `0x03`의 ON=`01`, OFF=`00`을 확인했습니다. 읽기·저장·재읽기 검증을 구현했습니다. |
| 공장 초기화 | 지원 계획 없음 | 공식 앱에서 제공하며 위험 대비 필요성이 낮아 이 프로젝트 범위에서 제외했습니다. |
| 마우스, 미디어, 매크로 | 미구현 | 키보드 HID 매핑 범위 밖의 기기 포맷 분석이 필요합니다. |
| 프로필 가져오기 및 내보내기 | 미구현 | 로컬 프로필 저장은 지원하지만 사용자 파일 입출력 UI는 없습니다. |

## 안전 원칙

- 확인된 슬립 값만 read-modify-write 방식으로 변경하며 나머지 설정 바이트를 보존합니다.
- 슬립 바이트가 확인된 `00/01`이 아니면 체크박스를 잠그고 매핑 저장 중에도 그 원본 바이트를 보존합니다.
- `최근 백업 복원`은 공장 초기화가 아니라 가장 최근 저장 직전 백업 복원입니다.
- 저장과 복원은 쓰기 API 성공만으로 완료 처리하지 않고 새 전체 재읽기 결과를 검사합니다.
